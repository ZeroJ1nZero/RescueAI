## Global constraints
- Preserve reference plan and input data; no fabricated poses, maps, detector results or performance.
- Depth internally meters; require explicit verified provenance for the OpenLORIS 0.001 scale.
- E0 30–60 s; E1 60–120 s, speed 0.25; timestamps remain unchanged.
- Separate synthetic unit/integration fixtures from measured-data experiments and Orin runs.
- E1/E2 cannot run without E0 validation, compatible ROS/RTAB-Map and real input.

## Review focus
- Corrupt images, row padding and endian depth must not silently become distances.
- Header/record timestamps can differ; preserve both and reject ambiguous/nonmonotonic replay.
- Matching must not reuse one depth for multiple RGB images or hide missing frames.
- Calibration direction, unknown alignment and IMU semantics must prevent false E0 success.
- Failed/blocked sessions must contain reasons, without empty placeholder maps or measurements.
